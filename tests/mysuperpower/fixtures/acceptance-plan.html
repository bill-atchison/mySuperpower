Overview

Goal: exercise the subagent-driven-development dispatch path against an HTML plan. This plan is a fixture. Its tasks are deliberately trivial and write only into a scratch directory.

Architecture: three tasks that build one small shell script in .superpowers/acceptance/, which is git-ignored. Tasks 1 and 2 both touch greet.sh, so the pre-flight conflict scan has a genuine pair to report.

Tech Stack: bash.

Global Constraints

  • Everything this plan creates lives under .superpowers/acceptance/, which is git-ignored. Nothing is committed.
  • The script must print exactly one line and exit 0.

Task 1 — Create the greeting script

Create .superpowers/acceptance/greet.sh

Interfaces — Produces: greet.sh, which Task 2 extends and Task 3 verifies.

  1. Step 1: Create the script 
    mkdir -p .superpowers/acceptance
cat > .superpowers/acceptance/greet.sh <<'EOF'
#!/usr/bin/env bash
echo "hello from the acceptance fixture"
EOF
chmod +x .superpowers/acceptance/greet.sh
  2. Step 2: Run it 
    bash .superpowers/acceptance/greet.sh

    Expected: hello from the acceptance fixture, exit 0.

  3. Step 3: Note the entity-decoding check

    This step exists so the brief carries escaped markup. The implementer must report, verbatim, the tag named here: strip the <meta http-equiv="refresh"> tag. If the brief shows &lt;meta&gt; instead of <meta>, the extraction is wrong and the task must stop.

Task 2 — Add a name argument

Modify .superpowers/acceptance/greet.sh

Interfaces — Consumes: greet.sh from Task 1. Produces: the same script, now accepting $1.

  1. Step 1: Accept an optional name 
    cat > .superpowers/acceptance/greet.sh <<'EOF'
#!/usr/bin/env bash
name=${1:-fixture}
echo "hello from the acceptance $name"
EOF
  2. Step 2: Run it both ways 
    bash .superpowers/acceptance/greet.sh
bash .superpowers/acceptance/greet.sh world

    Expected: hello from the acceptance fixture, then hello from the acceptance world.

Task 3 — Verify and clean up

Verify .superpowers/acceptance/greet.sh

Interfaces — Consumes: greet.sh from Task 2.

  1. Step 1: Confirm one line, exit 0 
    out=$(bash .superpowers/acceptance/greet.sh)
test "$(printf '%s' "$out" | wc -l)" -eq 0 && echo "single line: ok"
  2. Step 2: Remove the scratch directory 
    rm -rf .superpowers/acceptance
